# PicoID

Imprinted-proc inventory viewer for the Uncapped realm (WotLK 3.3.5a) — by Mhortai.

Lists every proc imprinted on equipped gear (name, spell ID, origin item, drop source, icons),
flags duplicates, shows hover damage/healing at imprinted magnitude plus scaling coefficients,
and shares full proc lists between players via offline, checksummed PICO strings.

Companion data addon: **PicoID Data** (LoadOnDemand tables), distributed with the realm's addon pack.

Source of record for the addon; deliverables (zip, Guide PDF, nutshell PDF, changelog) are attached
to each tagged release.
